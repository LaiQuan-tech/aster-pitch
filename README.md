# aster-pitch

亞斯特設計顧問 數位化系統 — **系統建置提案簡報（Apple 風全螢幕 pitch deck）**。

- 線上：<https://aster-pitch.vercel.app>
- 純靜態站（單一 `index.html`），**push 到 `main` → Vercel 自動部署**（framework=static）。
- 對應的實際系統：<https://aster-system.vercel.app>（另一個 repo `LaiQuan-tech/aster`）。

## 內容（11 張投影片）
封面 → 現況 → 三大痛點 → 解決方案 → 功能總覽 → 亮點·獎金自動分配 → 亮點·AI 專案進度追蹤 → 客製模組 → 技術與資安 → 時程與報價（12 週 / NT$850,000 未稅）→ 結尾。

時程與報價已合併為單頁總表：每一列同時呈現「第幾週 / 做什麼 / 多少錢」。該頁列數多，`#s9` 有三段依視窗高度分級的壓縮規則（基準 / `max-height:820px` / `max-height:700px`），改動該頁後務必重新確認各尺寸仍單屏容納。

品牌色取自萊乾官網 laiquan.co：奶油底 #fffbec ＋ 黑 #1a1a1a ＋ 亮黃金 #ffce00（深金 #9a7a00 用於強調文字）。
